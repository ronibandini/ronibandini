# Roni Bandini

**Maker**
Buenos Aires, Argentina

I build experimental machines at the intersection of **Machine Learning, physical computing, robotics, literature, electronic music and technological counterculture**.

Founder of **[Contracultura Maker](https://github.com/ronibandini/ContraculturaMaker)** — an initiative around technological autonomy, strange machines, hardware experimentation and critical approaches to technology.

### Main tools

`Python` · `C++` · `Arduino` · `ESP32` · `Raspberry Pi` · `Edge Impulse` · `LLMs` · `n8n` · `Linux` · `3D Modeling`
